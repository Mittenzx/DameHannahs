# Sensory Room — Editable Drawings

This folder contains editable SVG drawings of the proposed sensory room refurbishment at Dame Hannah Rogers Trust.

## Files

| File | Drawing No. | Description |
|------|-------------|-------------|
| `Floor_Plan.svg` | DHR-SR-01 | Top-down floor plan showing room layout and equipment positions |
| `North_Wall_Elevation.svg` | DHR-SR-02 | Front elevation of the feature/projection (north) wall |

## How to edit

**Inkscape** (free, recommended)
1. Download from [inkscape.org](https://inkscape.org)
2. Open the `.svg` file — all elements are named groups; click to select, drag to move
3. Double-click a group to enter it and edit individual parts (walls, labels, dimensions)
4. Save as SVG to keep editable, or export as PDF for sharing

**Adobe Illustrator / Affinity Designer**
- Open the `.svg` directly — all elements will be individually selectable

**Web browser (view only)**
- Drag and drop the `.svg` file into any browser tab to view without editing

**Microsoft Word / PowerPoint**
- Insert → Pictures → select the `.svg` file

## What is drawn

### Floor Plan (DHR-SR-01)
- Room outline with thick walls (~22px = 1m equivalent at 1:50 scale)
- Wall padding shown as hatched inner layer on all walls
- Padded floor area shown as light blue hatching
- Equipment positioned at approximate locations:
  - Corner Plinths (CP1, CP2) — NW and NE corners
  - Chromatube+ column (CHR) — centre room
  - HD Ultra Short Throw Projector (PROJ) — north wall, ceiling mount
  - Mirror Ball + Spotlight (MBL) — ceiling centre
  - Galaxy Star Projector (GSP) — NE ceiling
  - Fibre Optic Ceiling Panel (FOC) — NW ceiling
  - UV LED Light Bars (UV1, UV2) — east and west walls
  - LED Surround Lighting (ceiling perimeter) — dashed orange ring
  - Bluetooth Switch Panels (BT1–BT4) — wall-mounted
  - UV Reactive Stars / Solar System — SW ceiling

### North Wall Elevation (DHR-SR-02)
- Full face of the feature/projection wall (north wall, viewed from inside room)
- Projection screen area with dimensions (~3.3m × 1.85m indicative)
- Projector (ceiling-mounted above screen)
- Mirror Ball + Spotlight (ceiling, left of screen)
- Galaxy Star Projector (ceiling right)
- Fibre Optic ceiling panel (left)
- UV LED Light Bars (×2, wall-mounted, left and right)
- Chromatube+ column (free-standing, left)
- Corner Plinth + mirror (right corner)
- Wall and floor padding

## Important notes

- All dimensions are **indicative only** — actual room dimensions must be confirmed on site
- Equipment positions are approximate and subject to So Sensory's site survey
- Electrical conduit, socket, and cable tray routes are **not shown** (electrical survey outstanding — gap T2)
- Laser Lights (×2), UV Reactive Stars, and ceiling rigging details require contractor confirmation
